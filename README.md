# EcoPréstamo

**Abrir la aplicación** · [https://johandc34.github.io/ecoprestamo/](https://johandc34.github.io/ecoprestamo/)

EcoPréstamo permite administrar el inventario de un centro comunitario de préstamo de equipos.

## Cómo usar EcoPréstamo

1. Registra equipos y consulta las unidades disponibles en **Inventario**.
2. Registra la salida y la fecha prevista de devolución en **Préstamos**. El panel muestra los préstamos vencidos.
3. Registra devoluciones parciales o completas para liberar unidades del inventario.
4. Consulta los movimientos en **Historial** y exporta los resultados a CSV.

Para probar la aplicación con datos de ejemplo, ve a **Ayuda → Cargar demostración**.

## GitHub Pages

GitHub Pages publica los archivos HTML, CSS y JavaScript de la rama `main`. Puedes abrir la aplicación desde el enlace de arriba. Los equipos, préstamos y devoluciones se guardan en el navegador mediante `localStorage`, por lo que cada navegador conserva sus propios registros.
